# Ramsydex Global Logistics

An enterprise-grade commercial logistics and supply chain digital platform designed for **Ramsydex Global Logistics Sdn Bhd**, headquartered at the Central Malaysia Logistics Park (Shah Alam / Bukit Jelutong).

---

## 🚀 Key Features

- **Multi-Modal Freight Transportation:** Domestic linehauls, cross-border bonded trucking (Singapore & Thailand), maritime container drayage (Port Klang), and express airfreight (KLIA Cargo Village).
- **Direct EDI Customs Brokerage:** In-house licensed customs agency with direct electronic integration to the Royal Malaysian Customs Department (Sistem Maklumat Kastam – SMK).
- **Specialized Quality Control (QC) Protocol:** Dedicated inbound staging audit including structural carton checks, GS1 barcode / SKU validation, and 4-hour digital photo reports.
- **Central Malaysia Staging Capabilities:** High-bay bonded pallet racking, cross-docking bays, climate-controlled staging, and 24/7 biometric surveillance.
- **Interactive Global Corridors & Rate Estimator:** Real-time corridor lookup and dynamic rate calculator with instant quote handoff.
- **Commercial Quote Desk:** Fast single-page quote submission with 24-hour review commitment, PDPA compliance, and direct WhatsApp dispatch routing.
- **Dual Theme Support:** High-contrast Dark and Light modes styled with Tailwind CSS v4 and brand aerodynamic accents.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 (with custom CSS variables and `@custom-variant dark`)
- **Icons:** Lucide React
- **Linter:** Oxlint

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/ChibykeOS/ramsydex-logistics.git
cd ramsydex-logistics
npm install
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:5173` to explore the application.

### Production Build

```bash
npm run build
npm run preview
```
